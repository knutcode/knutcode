## :robot: How I work: AI first

Most of my day runs through AI agents. Instead of one general assistant, I run a small team of specialised agents, each owning one job with its own tools, memory and rules:

- **Support triage**: reads new tickets every morning, does first-line diagnosis and routes the work to the right specialist
- **Platform configuration**: tenant settings, translations and data pushes
- **Report templates and client reports**: building, fixing and checking the PDF and Excel reports customers receive
- **Office and inbox**: calendar, mail drafts and a daily priority list
- **Ops**: the automations, scheduled checks and dashboards that keep the rest running

A few principles I hold to:

- **Humans decide, agents prepare.** Agents draft replies, PRs and releases; a person sends, merges and ships. Production changes need explicit approval.
- **Prove it where it shows.** "Fixed" means tested on the customer's actual case, in the UI, the PDF or the API, not just in theory.
- **Small, focused agents beat one big prompt.** Clear ownership, shared context and hand-offs between agents.
- **Automate the boring parts.** If I do it twice, it becomes a check, a script or a skill.
